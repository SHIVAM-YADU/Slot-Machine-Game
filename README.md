# 🎰 Python Slot Machine Game

A simple command-line based **Slot Machine Game** built using Python.  
This project simulates a casino-style slot machine where users can deposit money, place bets, and spin to win rewards.

---

## 🚀 Features

- 💰 Deposit system
- 🎯 Bet on multiple lines (1–3)
- 🎰 Random slot machine spins
- 📊 Balance tracking
- 🧮 Win calculation based on symbol matching
- ✅ Input validation for better user experience

---

## 🧠 How It Works

1. User deposits money.
2. User selects:
   - Number of lines to bet on
   - Amount to bet per line
3. Slot machine generates random symbols.
4. If symbols match across a line → user wins 💸
5. Balance updates after each spin.
6. User can continue or quit anytime.

---

## 🎮 Game Rules

- Maximum lines: **3**
- Minimum bet: **$1**
- Maximum bet: **$100**

### Symbols & Values

| Symbol | Frequency | Value |
|--------|----------|-------|
| A      | 2        | 5x    |
| B      | 4        | 4x    |
| C      | 6        | 3x    |
| D      | 8        | 2x    |

- Rare symbols (like **A**) give higher rewards.
- Common symbols (like **D**) give lower rewards.
